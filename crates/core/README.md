# archivindex-truthsocial

Types for reading and writing Truth Social API responses, including statuses, accounts, media
attachments, tags, and groups. The `url` module classifies Truth Social API URLs.

These types are shared by the live HTTP client in `archivindex-truthsocial-api` and the Wayback
Machine archive integration in `archivindex-truthsocial-wbm`.
